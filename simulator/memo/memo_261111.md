## B. Stage AA — `WAIT children:<id>`, conformance (g)

If no child is live when the WAIT is reached, it completes at once with a zero-wait line, in the arrival step or inside an occupancy like any zero-wait line. [confirmed on hand workloads]

The harness pairs that line with the program's WAIT as with any other (`primitives.py`, `next_wait`). **Stage AD** (`steps/sim_ad.cpp`, ported to `src/sim.cpp`; `simulator@1ce6b8807157`), written by 인지오:

- The boot entry, index 0, always applies. `fix-object` and `fix-tree` write no time but 0, so their `T_end` is 0.

### L2. Two causes

1. **Under EDF the frame chain takes the whole lane** (`c3-evening`, the four chain-scaled `c2` variants, the two `c7-gaming` variants). In `c3-evening` from 60 s to 300 s the lane is busy all the time with the chain's stages, and `steam` and `chat` get nothing. The executor has no starvation net by design (`docs/memos/2026-10-08-declared-scheduling-class.md` §2); the guard is the bound.
2. **The cap and the idle band held each other** (`c2-p1b`; `c1-backup`'s hidden wait). `capped_now()` counted an idle task the idle band held as runnable non-batch work, so the cap bit the batch-class editor. `any_nonidle_runnable()` counts the capped editor as runnable, so the idle task stayed held. In `c2-p1b` from 60 s to 99.4 s the lane was 4.8 % busy with both runnable. In all six files with an idle task and a cap the editor was parked, 32 to 982 times, and lane use fell in four of them.

### L3. Decided (인지오)

1. **An idle-class task does not turn the cap on.** The ceiling applies while a non-batch task of a non-idle class is runnable (`docs/recognition-vocabulary.md` §2 and its change log; the declared-class memo §2). Stage AE, L4.
2. **No starvation net.** The guard flags the five EDF runs as designed, and none is a run the criterion reads: one reporting file and four variants. The cold smoke (10.3) reads the guard table of every condition, and the net is reopened if a judging file fails.
3. **The guard's reading stays.** `tools/wait_check.py` counts beside it and is rerun on the smoke's traces.
4. **A variant's failed guard makes its line's count unavailable**, as a boot default's and a band table's is. 인지오's sub-task 10.6, in the evaluator.

### L4. Stage AE — the cap beside the idle class

`capped_now()` is true while a non-batch task of a non-idle class is runnable (`steps/sim_ae.cpp`, ported to `src/sim.cpp`; `simulator@0d323c84470a`). A batch-class task beside a runnable idle task alone runs uncapped, and the idle task runs when it blocks. A file with no idle task is unchanged.
