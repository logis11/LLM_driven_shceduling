## D10 — the trace replay: the compiler's `replay` param, the six streams, the replay set built (2026-10-09)

Spec decision 12, the replay half (the grill of 2026-10-09, Q1–Q6). `dataset/tools/wlc/compiler.py`, "trace replay": an entry whose params carry `replay: {stream, sampling: per-task, source}` compiles each task from `dataset/replay/<stream>.json.gz` — one pooled repeat, its `kind` fixing the rows' columns: `wakes` (a measured entry: the tree's merged wakes, `[t_us, run_us, thread]`), `cycles` (a periodic entry: `[start_us, work_us, length_us]`), `runs` (a batch entry: `[t_us, run_us, block_us]`). A task group takes distinct streams of the repeat, each task its own offset.
