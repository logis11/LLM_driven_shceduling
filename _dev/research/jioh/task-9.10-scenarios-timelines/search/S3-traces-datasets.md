## 3. Not found

**T1 — application co-occurrence on real desktops**

- A public dataset of process or window lists sampled on real users' desktops (Linux in particular) that names which programs are open together and for how long: not found. Closest: S3-02 (per-minute count of open top-level windows and the foreground program, 12 users, Windows and X11 Linux, no list of open programs) and S3-01 (lab, Windows 7, reconstructed from process start/exit events). Leads that do not deliver: Giovanini et al. 31-user Windows 10 per-minute process lists (S3-05, not released); LANL host event logs with Windows process start/end (download gated by an e-mail form, enterprise hosts, not submitted); Clarkson II (keystrokes only); Activity Finder Linux multitasking study (S3-06, no released data). Searches: WebSearch `dataset running processes sampled real user desktop computers Linux "process list" snapshots …`, `public dataset desktop "window switching" OR "application switching" logs …`, `"number of open applications" OR "applications open simultaneously" …`, Zenodo API (6 queries) — search log rows above.
- Per-population, per-OS telemetry of how many applications are open at once: not found (a 2011 Statista survey item is paywalled and is a survey; KDE's telemetry policy has no published results).

**T2 — foreground focus and switching**

- A public Linux focus log with sub-minute timestamps and window titles from real users: not found; BEHACOM's Linux users (S3-02) are at one-minute resolution with executable names only.
- OS or browser telemetry releases with focus dwell or switch rates: not found (searches above; browser-side tab telemetry is under T3).
- DesktopBench / FOCAL (S3-03) carries application name and window title per action but is template-composed, not observed, and has no download location; the full TaskPit dataset (18 employees) is not public, only a two-person excerpt (S3-04).

**T4 — games and their companions on Linux**

- **Full thread inventory of a Proton game in normal play** with names and per-thread CPU: the only complete named list found (S3-20) is from a deadlocked game; S3-22 gives counts without names; S3-23 gives names of busy threads only. Searches: `"ps -eLf"`, `"task/*/comm"`, `"top -H"`, `"ps -T -p"`, `"ps -eLo" wine`, `"dxvk-cs" "%CPU"` etc. (search log rows 1, 4, 8–9).
- **Thread names of the Steam client itself** (`steam` 32-bit process, e.g. `IPC:CSteamEngin` seen as a process-column entry in steam-for-linux #13517's `ps.log` after the game had exited; not used): no listing beside a running game found.
- **Voice chat (Discord etc.) or a browser beside a game on Linux, in a process listing:** none found; S3-22 shows only terminal apps beside the game. Not searched exhaustively beyond the Steam/Proton/gamescope queries above.
- **The default value of "Allow downloads during gameplay" observed on a Linux client** (as opposed to stated by Steam documentation or press): not found; the reports above are all from users who had turned it off. Query: `Steam "Allow downloads during gameplay" default off unchecked Linux` (WebSearch) — results are documentation/secondary only.
- **Frequency of Steam downloads/updates during gameplay** (per hour or per session): no source gives a rate; S3-26 is one session's retry loop, S3-28d one client update check.
- **gamescope's own wakeup/repaint cadence measured with a tracer** (e.g. `perf sched`) on a desktop: not found; only client fps readouts (S3-29).

**T5 — background jobs a desktop runs unasked**

- **A stock Ubuntu 24.04 desktop `systemctl list-timers --all` with NEXT/LAST columns.** Closest: S3-39 (24.04 inventory without times, non-stock), S3-33 (Mint 21.1 with times), S3-35a (Mint 22.1 inventory + run times). Searches: Ask Ubuntu API (3 queries), Launchpad `searchTasks` `list-timers`, Ubuntu Discourse search.json (3 queries), GitHub issue search (5 queries), WebSearch (2 queries) — see log.
- **Typical durations of each job across many desktops** (man-db, plocate updatedb, fstrim, logrotate, dpkg-db-backup, fwupd-refresh, packagekit refresh, freshclam): only single-machine journal excerpts (S3-35a–d). No dataset aggregates these. No observation found for fstrim, e2scrub_all, freshclam, packagekit refresh durations; colon-quoted GitHub searches for `dpkg-db-backup.service: Consumed`, `fwupd-refresh.service: Consumed`, `apt-daily-upgrade.service: Consumed`, `localsearch-3.service: Consumed`, `tracker-miner-fs-3.service: Consumed`, `logrotate.service: Consumed` failed in the gh CLI and were not retried through the REST endpoint.
- **DKMS autoinstall on a desktop after a kernel update with a successful make.log and timing.** Desktop-posted make.logs found were failures (S3-31); successful build timings come only from Ubuntu's 2-vCPU test VMs (S3-32). Fedora akmods, Arch dkms hook timings not searched.
- **Which DKMS modules Ubuntu desktops build.** Ubuntu popcon is no longer published (`Thanks!`; Wayback 2021 copy stale) — Debian popcon only (S3-30), servers and desktops mixed.
- **Backups (Déjà Dup, Timeshift, Snapper) schedules/durations as observed on desktops; ClamAV scan schedules; firmware-update runs.** Not searched beyond popcon installation counts (S3-30); no observation found.
- **How often an indexer full rescan happens across users.** Only trigger reports (S3-36, S3-37); no rate data.

**T3 and T10 — browser tabs and renderer processes; operation rates and video-call processes**

- **T3 — renderer processes per tab set on desktop Linux (Chromium/Chrome): no observation found** that lists `--type=renderer` processes (ps, `chrome://process-internals`, task manager) for a stated set of open tabs/sites on Linux. Searches: WebSearch rows 11–19 of the log, `gh search issues` with `--renderer-client-id`/`type=renderer` (0 relevant hits), Vivaldi forum (no listing). The only Linux observation with a tab count is S3-42 (file descriptors, 2015). S3-02 (BEHACOM) — per-minute count of processes named like the foreground app, 10–17 for `chrome` on two Linux users — is the closest dataset-side signal; it does not tie counts to tab sets.
- **T3 — number of tabs visible at once:** no telemetry metric or dataset found that records visible tabs; S3-40 and S3-41 give windows (≤ one visible tab each, absent split view) and S3-47 gives one user's tab/window shares.
- **T3 — Chrome tab/window counts:** Chrome UMA histograms (e.g. tab counts) are not public; no public Chrome dataset found (searches rows 2, 11–19).
- **T10 — e-mail with/without attachment from telemetry:** Thunderbird's public telemetry has no send count (S3-44); Enron (S3-46) supplies sends, attachments only by marker. SWELL-KW (S3-01) has Outlook "Send" clicks.
- **T10 — image filters, video preview renders, chat messages received per hour:** no downloadable log or telemetry found; GIMP, darktable, Kdenlive and chat clients publish no usage telemetry located in these searches (not searched exhaustively; searches limited to the queries above).
- **T10 — video call process/thread structure on Linux:** no `top -H` / `ps -L` / thread-name (`comm`) listing during a call found for Zoom, Teams (teams-for-linux), Google Meet or Jitsi in a browser. Closest: Zoom's process tree outside a call (S3-45) and qualitative in-call CPU reports (S3-43, S3-48). Searches: log rows 21–29 (Rocky, Fedora and Arch threads without listings; Jitsi forum search 403; teams-for-linux and jitsi-meet issue searches).
