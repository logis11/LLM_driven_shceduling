Three scales: hardware-state governors at 0.5 ms–80 ms (the cpufreq governors, the interactive governor, the migration cost), daemon-level tuning switches at 5–30 s (GameMode, tuned, systemd-oomd), capacity provisioning at 5–15 min (the autoscalers, the AWS cooldown, route flap damping). The daemon is a daemon-level switch — it observes the process set and changes the scheduler's configuration — so the comparable range is 5–30 s, tuned the nearest analogue. The three values in that range are the flap-stress set's 5, 10 and 30 s intervals, each tagged with its source (`feral-gamemode`, `tuned`, `systemd-oomd`: `docs/references.md`, `dataset/sources.yaml`); 2 s is a point below the range, labelled design. Windows contributes the form (a hold in units of a check interval) and no value.

## D2 — composition: a C1 task set in a segment (2026-10-11)

Spec decisions 1–3 (9.10 D44). `dataset/tools/gen/compose.py`. A placement's tasks are the mode's C1 tasks, ids suffixed `-s<k>` (two task sets never collide), the C1 arrive offset kept and shifted to the segment's start; a segment-bound task departs at `alive_until`; a finite task's `total_work` (millisecond precision) or `spawn_count` (rounded, at least 1) is the C1 value × (the span the task is alive in) / (the C1 segment's length less the C1 arrive offset), and that `source` entry becomes `design` when the value changed — a value the ratio leaves unchanged keeps its C1 tag (an indexing or render segment of 60 s). In a segment of 4 s or less the finite task arrives at the segment's start (its 2 s offset would fall on the boundary). The segment carries the C1 segment's mode, attributes, scenario (and familiarity); the input window keeps the C1's margins (start + 2 s, end − 2 s) within the label segment only, dropped when empty; the focus interval over the segment the same way; each operation at its C1 fraction of its task's window, dropped with the window — so the return grid's 2 s middle segment shows B with no keystroke and no operation. `meta.demand: calibration`, as every C1 file declares (the file is not designed to hold contention). The header names the set, the cell and the design label; the file is not committed.
