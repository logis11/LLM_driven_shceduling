## Per item

### 1–4. `heartbeat`, `heartbeat_work` (median and sigma)

- No class found a Linux observation of an idle renderer's, an Electron client's, a Steam helper's or a Zoom helper's wake cadence or CPU per wake as a distribution (S1 §3 T1–T3; S2 §3 T1–T2; S3 §3 T1–T2). What exists are prose CPU-share readings and wake-rate lower bounds (table above).
- Nearest to a cadence: S3-22's `steamwebhelper` thread at a ≈ 5–6 ms `poll` cycle (three cycles quoted, idle offscreen; reader's computation); S3-01's "> 60" wake-ups/s per Chrome process idle on `chrome://about` (Chrome 46, 2015); S3-08's 26.9 + 15.0 wake-ups/s (2009, context).
- Mechanisms that bound an idle renderer's main-thread cadence, from Chromium source (S2-06): JS timer wake-ups aligned to 1 per second once a page is hidden, 1 per minute after a 5-minute grace (1 minute if the page had finished loading), 3 ms per throttled wake-up window, a 1 % CPU-time budget from 10 s after backgrounding; task-queue freezing (`kStopInBackground`) disabled on desktop; the process's other threads and the compositor are not bound by them. Chromium's Memory Saver discards a hidden tab after 2/4/6 h and samples background CPU every minute with a 5 % threshold (S2-07) — no 5- or 10-minute run reaches a discard. Electron windows inherit the throttling by default (`backgroundThrottling`, S2-08).
- Mechanisms that bound an idle comms client's cadence: Discord's gateway heartbeat every server-assigned `heartbeat_interval` (documented example 45 000 ms, first one jittered; S2-10); Matrix `/sync` long-poll with client-chosen `timeout` (spec example 30 000 ms; matrix-js-sdk `pollTimeout` 30 000 ms, local abort at 30 + 80 s — S2-12, S2-13), so an idle Element wakes on one HTTP round trip per ≈ 30 s plus the renderer's own timers; Slack's legacy RTM "a ping every few seconds", Socket Mode states no interval (S2-11); Teams-for-Linux's own idle polling every 10 s / 2 s, off by default (S2-17). Each is a protocol interval, recorded as a mechanism, not an observation.
- Distribution form: no source in any class reports a per-wake distribution for any of these programs; the sigmas have no external referent (S1, S2, S3 not-found).
