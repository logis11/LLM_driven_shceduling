## Decisions

1. **The title changes.** W-0957 makes the change conditional ("if the title changes"). Code and the latest record agree that an archetype is not one process: the archetype plan's §1 dropped "one process" for "one kind of program" in `18127cc9`, and the library's measured entries merge a whole process tree into one task (`compiler-child`: six tasks). Spec decision 3 puts the code and the latest record above the current doc, so the title follows them.
2. **"프로그램 한 종류", in Korean.** The plan's term is "one kind of program"; vol-06's 재구축 이후 note renders it "한 종류의 프로그램". In vol-02, English "program" names the archetype's op template (§1.4 "archetype의 program은 '틀'입니다"), while Korean "프로그램" names a real application (`:13` "실제 프로그램을 돌려", `:39`). The Korean word keeps the two apart; "프로그램 한 종류" keeps the title's word order ("process 하나를 …").
3. **The README follows verbatim** in the same change (the row's instruction); its "답하는 질문" cell is the volume's bold question, unchanged.
4. **W-0952's wording follows vol-04's** (G3's N2) for the three kinds and the manifest's per-file streams, so the two volumes describe the variant alike; the stream kinds' Korean glosses are written from the compiler's code (wakes at their times with their runs; runs and the block after each until the bind's CPU; the cycle grid and period kept, the k-th tick taking the k-th observed cycle's work).
