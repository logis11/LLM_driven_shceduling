## Decisions

1. **W-0873: restated, not replaced by a pointer.** The building plan's §2 pin keeps the table as the quick-reference inventory. Its scenario column (S1–S18) is not in the archetype plan's §4. So the table follows the archetype plan's four compile-path groups and keeps its own columns, rather than collapsing into a pointer. `cpu-batch`'s `spoof` program was added: it is in the archetype plan's row and in the code (`compiler.py:521`, one uninterrupted RUN; `c6-spoof` binds it), and its scenario S2 is the generator's map (`gen/compose.py` `SCENARIO_OF_PROGRAM`) and `c6-spoof`'s segment tags.
2. **W-0884 (5): every campaign records with `-a`, not only `session`.** The review finding named `session` alone. The trace sentence describes the run scripts, and every `perf sched record` in them carries `-a`, run from the harness CPUs: `campaign/run.sh:152`, `:255`; `desktop/run.sh:127`; `desktop/launch.sh:58`; `background/run.sh:212`; `build/run.sh:106`; `session/run.sh:116`, `:668`. Precedence is code first (spec decision 3). The data carries `meas-ci` tags of six workflows only: background 145, interactive 150, desktop 81, build 24, session 13, playback 8 (grep over `archetypes.yaml`, the core timelines, `grids.yaml`, `variants.yaml`). So `names` joined the four as a workflow that carries no dataset value. The building plan's name rule and the scenario catalog's note 4 cite it. `costs` is cited by the research proposal (`meas-ci:costs:2026-10-08`), and each other workflow is described from its file's header comment. The taskstats listener appears only in `background/run.sh` and `build/run.sh`, "registered on the measured CPU", and the sentence now says so instead of "its cpumask".
3. **W-0903 (2): K06's sentence merged into the bullet.** The bullet already opens "**Switching structure:** unsourced", so K06's "Hub-and-spoke switching is unsourced." became "unsourced, hub-and-spoke switching included". Restating it as a second sentence would only repeat that word. The history clause is gone, as K06's grounds ask (`_dev/research/jioh/research-slice-workflow.md:23`).
4. **W-0884 (4): the sentence's last clause kept.** It ends "`c6-dual` is `oversubscribed`". C2's and C3's files are `oversubscribed` too, by the default (`timeline.py:52`; no `demand` in their timelines or in `c2-pairs.variant.yaml`). The sentence lists the calibration declarers explicitly, so they were not added.
5. **W-0886: the three offsets not re-run.** The row changes only what run they are tied to. The k ≥ 1 statement rests on `sim.cpp:674–677` (above).
6. **W-0941 (in the scenario catalog's rows file) not taken in the archetype plan.** Its option to widen the archetype plan's §3 rule ("Counts never appear in the scenario catalog") is not taken here. That rule matches the data: the count is bound in `c1-browsing` as `count: 4` with its source. The row is the scenario catalog's chunk's.
