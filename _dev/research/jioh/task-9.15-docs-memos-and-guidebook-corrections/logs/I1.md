1. **"프로그램 한 종류"**, the term the rows name and H2 used for vol-02 (its decision 2: Korean "프로그램" names a real application, English `program` the archetype's op template; vol-01 `:494` keeps "여섯 primitive로 된 program 틀" in English as it was). I2 used the same term in the coreset guide.
2. **vol-01 `:498`: "프로그램 한 종류의 행동"**, not the literal "프로그램 한 종류". The row restates "process 행동의 한 종류" to "프로그램 한 종류", nothing else; the literal swap ("항목 하나가 프로그램 한 종류입니다") would drop "행동" and make an entry a program rather than the behaviour it records, under §3.2's heading "archetype: 행동의 library". Reordering keeps every word but the replaced one; W-0963 words its change the same way ("the behaviour of 프로그램 한 종류").
3. **W-0963's lines read "프로그램 한 종류의 행동"** as the row says; the examples in parentheses (`code-editor`, `build-orchestrator`, `cpu-batch`) follow "행동" as before.
4. **Where the sentence has its own determiner** ("어떤 종류의 process", "VS Code라는 종류의 process"), only the noun changes to 프로그램, as H2's N1 did at vol-02 `:9` ("이런 종류의 프로그램은"). Particles adjusted (프로그램은, 프로그램이).
5. **vol-01 §3.8's diagram stays until the building plan's does** (N4): code and the latest record (the archetype plan §1, K04's P1) say "one kind of program", but the diagram is a rendering of another doc; the stale text is the building plan's, so the row goes there (X1) with vol-01 following in the same change.
