How copies were made. Web pages and PDFs were fetched with `curl` (no proxy); GitHub files with `gh api -H "Accept: application/vnd.github.raw" repos/<owner>/<repo>/contents/<path>?ref=<commit or tag>`; unreachable vendor PDFs were read from Internet Archive Wayback copies fetched with the raw `id_` form (`https://web.archive.org/web/<timestamp>id_/<url>`), identified below by capture timestamp. Web search was used only to locate copies and is not cited. PDF text was extracted with **pypdf 6.19.0** installed in a venv in the session scratchpad (pdfminer.six was installed alongside but not used); pypdf renders the "fi" ligature as "ﬁ" and inserts stray spaces inside some words ("a fter", "e ach") — in the quotes below the ligature is written "fi" and the stray spaces are removed; nothing else is changed. HTML pages were reduced to text by the reader's tag-stripping script; where the page uses a superscript, the text loses it (10<sup>9</sup> becomes "109"), and the quotes below write such powers as `10^9` with a note. The Squeeze Chart workbook was read with openpyxl. Every file quoted is saved under `sources/T9-S2-NN/` (gitignored) and identified here by URL or commit, version and SHA-256.

T9 is an input, not a response-side value, so a document from any platform is a candidate with its platform, population and date named; age is recorded, not a reason to exclude. Topics T1–T8 are outside this addendum and are not assessed per candidate.

Where the reader counted files in a downloaded input archive, the count is labelled **reader's own**, the command is given, and it locates what a document leaves out — it is not a value from the document.
